01

CLASSIFICATION · RARE-EVENT DETECTION · MLOPS

AML transaction detection

Prioritize suspicious transactions within a fixed review budget.

GitHub ↗

The problem

Rules-based screening can generate a large alert queue. I investigated whether ML could surface more laundering transactions when only 500 alerts could be reviewed.

What I built

A DVC pipeline using 5.08 million synthetic IBM transactions, prior-only history and graph features, time-aware validation, XGBoost, and MLflow experiment tracking.

What this demonstrates

Domain-informed feature engineering, leakage-aware evaluation, and a comparison that connects model quality to review capacity.

PythonXGBoostDVCMLflow
